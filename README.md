### Step 5:

### Step 6:

Generate candidate itemsets **C1, C2, C3, ...** and calculate their support counts.

### Step 7:

Remove the itemsets whose support count is less than the minimum support count and generate frequent itemsets **L1, L2, L3, ...**.

### Step 8:

Execute the program and analyze the frequent itemsets generated by the Apriori Algorithm.

## PROGRAM:

```python
from itertools import combinations

T = [
    ['Bread','Milk'],
    ['Bread','Butter','Juice','Eggs'],
    ['Milk','Butter','Juice','Jam'],
    ['Bread','Milk','Butter','Juice'],
    ['Bread','Milk','Butter','Jam']
]

min_support = 2
items = sorted(set(x for t in T for x in t))

for k in range(1, 5):
    print("\nC" + str(k))

    candidates = combinations(items, k)
    frequent = []

    for c in candidates:
        support = sum(set(c).issubset(t) for t in T)
        print(c, "=", support)

        if support >= min_support:
            frequent.append((c, support))

    print("L" + str(k))
    for c, support in frequent:
        print(c, "=", support)

    if not frequent:
        break
```
